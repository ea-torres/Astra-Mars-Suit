# ASTRA MARS SUIT · Helmet view

Web Simulation of a martian EVA with HoloConnect AI and a patch measuring 3 analytics.
(glucose, lactate and an H₂O₂ index) on Alex, our test astronaut.

## States
1. Normal. 2. Low glucose (Requests authorization for glucagon or gel). 3. Unresponsive (preauthorized emergency protocol).
Además: alertas de lactato y H₂O₂, y tormenta de polvo.
